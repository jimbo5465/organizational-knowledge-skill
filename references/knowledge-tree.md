# Official Knowledge Tree Reference

## Purpose

This file defines the official organizational Knowledge Tree used for
knowledge classification and metadata assignment.

The AI must use this taxonomy as a controlled reference.

The AI MUST NOT:

- Invent new Knowledge Tree nodes.
- Rename existing nodes.
- Merge nodes.
- Move nodes.
- Create alternative categories.
- Translate user-selected taxonomy values into different organizational
  categories.

When preparing a DANA draft, preserve the selected Knowledge Tree path.
